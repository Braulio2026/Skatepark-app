# 🛹 Skate-Routes Costa Rica

Skate-Routes is a web app that helps users find skateparks and highways that take them safely to every skatepark in Costa RIca.
The app works both online and offline using Service Workers.

---

## 🚀 Features

- 📍 Map of skateparks
- 🛍 Skate shop directory
- 📶 Offline mode (PWA)
- 📱 Mobile responsive

---

## 🛠 Tech Stack

- HTML
- CSS
- JavaScript
- Leaflet.js
- GitHub Pages

---

## 📦 Installation

1. Clone the repository:
   git clone https://github.com/braulio-ortiz/skate-routes-cr.git

2. Open the folder:
   cd skate-routes-cr

3. Open index.html in your browser
   OR use Live Server in VS Code
